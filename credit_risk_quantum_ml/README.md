# Projeto de Risco de Crédito com Machine Learning Quântico

Este projeto demonstra como utilizar Qiskit Machine Learning para previsão de inadimplência utilizando modelos quânticos e comparando com algoritmos clássicos.

Os dados sintéticos são gerados com **10.000** registros contendo variáveis tradicionalmente empregadas pelo mercado, como renda, score de crédito, utilização de limite e histórico de atrasos.

Execute `python main.py` para rodar todo o pipeline.
